# Модуль обучения и оценки

Здесь будет Python-модуль обучения и оценки. Пока есть только этот README.
Первая задача - офлайн-сравнение потоковых, графовых и совместных признаков.

Планируются схема признаков с номером версии, одинаковые
преобразования train/test, сохранение модели и выбор порога на validation. Isolation Forest - кандидат
для baseline на проверенном нормальном фоне. Окончательный метод будет выбран
по результатам экспериментов. Оценка аномальности не является вероятностью атаки.

Связанные захваты и изменённые копии потоков не разделяются между выборками.
Отложенные сценарии не используются при обучении и настройке. Шум обучающих
меток и устойчивость к изменениям трафика проверяются отдельными экспериментами.

HTTP-инференс добавляется после офлайн-прототипа. Содержимое пакетов не нужно
для базового набора признаков. Методы RAPIER и NetMasquerade
изучаются для отдельных экспериментов. К модулю они пока не подключены.

См. [протокол экспериментов](../../docs/RESEARCH_PROTOCOL.md)
и [план реализации](../../docs/TASK_BREAKDOWN.md).
