# Порядок разработки

Основная ветка проекта - `main`. Изменения вносятся через отдельные ветки и
pull request. Перед объединением pull request должна успешно завершиться
проверка `Quality Gate / Format, build and test`.

Militantyx является монорепозиторием. Изменение общего контракта между
компонентами должно сопровождаться обновлением всех его потребителей и
соответствующих интеграционных тестов.

## Локальная настройка

После клонирования репозитория необходимо включить версионируемые Git-хуки:

```bash
scripts/install-hooks.sh
```

Хук `pre-commit` проверяет форматирование и пробельные символы. Хук `pre-push`
проверяет форматирование, выполняет статический анализ, сборку и тесты всех
существующих компонентов.

## Команды

```bash
scripts/format.sh       # привести файлы к принятому стилю
scripts/check-format.sh # проверить форматирование без изменения файлов
scripts/run-tests.sh    # собрать проект и выполнить тесты
scripts/verify.sh       # выполнить все обязательные проверки
```

Для C++ применяется конфигурация clang-format на основе стиля Microsoft.
Изменения не объединяются с `main`, если обязательная CI-проверка завершилась
ошибкой.
