# Минимально жизнеспособная версия системы

Минимально жизнеспособная версия системы предназначена для анализа сетевого
трафика, выявления аномальных сетевых потоков и отображения результатов в
веб-интерфейсе.

## Функциональные возможности

- обработка PCAP-файлов;
- захват трафика с интерфейса Linux с применением AF_PACKET, PACKET_MMAP и
  TPACKET_V3;
- разбор Ethernet, IPv4, TCP и UDP;
- формирование двунаправленных потоков по 5-tuple;
- вычисление статистических характеристик потоков;
- обнаружение аномалий завершённых потоков методом Isolation Forest;
- пакетная запись потоков и предупреждений в ClickHouse;
- предоставление данных через REST API и WebSocket;
- визуализация статистики, потоков и предупреждений в веб-интерфейсе.

## Ограничения

- поддерживается только IPv4;
- TLS/HTTPS не расшифровывается;
- QUIC не анализируется на прикладном уровне;
- в хранилище записываются метаданные и статистика, а не содержимое пакетов;
- система формирует предупреждения и не выполняет автоматическую блокировку
  трафика.

## Критерий готовности

При обработке подготовленного PCAP-файла система должна сформировать записи
сетевых потоков, определить оценку их аномальности, записать результаты в
ClickHouse и отобразить новые предупреждения в веб-интерфейсе без перезагрузки
страницы.
