# Технологический стек

## Используется сейчас

| Назначение | Технологии | Фактическое состояние |
|---|---|---|
| C++-проект | C++23, CMake | Собирается библиотека логирования |
| Журналирование | spdlog | Есть адаптер и smoke-тест |
| Тестирование | Catch2 3, CTest | Подключены; PCAP-тест - заглушка |
| Проверки | clang-format, clang-tidy, ShellCheck, GitHub Actions | Есть скрипты и workflow |
| Контейнерный каркас | Docker, Compose, ClickHouse | Сенсор и интеграция с БД отсутствуют |

## Планируется для исследования

| Назначение | Выбор | Причина |
|---|---|---|
| Чтение и подготовка трафика | C++23, классический PCAP | Офлайн-проверки без live-захвата |
| Потоки и граф | C++-модули core | Сохранение связи графа с исходными потоками |
| Обучение и эксперименты | Python, scikit-learn | Повторяемое сравнение числовых признаков |
| Исходная модель | Isolation Forest, кандидат | Предложен в прежнем плане; нужно проверить на графовых признаках |
| Результат первого прототипа | Файлы признаков, оценок и манифестов | Можно проверить метод до интеграции сервисов |

Графовая библиотека и окончательная модель пока не выбраны.
FlowPrint, HyperVision, RAPIER и NetMasquerade изучаются как источники
методов. К Militantyx они пока не подключены.

## Расширения

ClickHouse, Drogon, React/TypeScript/Vite и Linux AF_PACKET/PACKET_MMAP/TPACKET_V3
планируются после офлайн-эксперимента. ML-сервис и интерфейс
ещё не реализованы. LLM для оценки аномалий не требуется.

Зависимости и версии фиксируются в каждом эксперименте. Скорость обработки
и качество модели проверяются экспериментально.
