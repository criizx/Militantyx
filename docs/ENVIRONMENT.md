# Среда выполнения

## Целевая среда

- операционная система: Ubuntu 24.04 LTS;
- архитектура: x86_64;
- компилятор: GCC или Clang с поддержкой C++23;
- система сборки: CMake 3.25 или новее;
- контейнеризация: Docker и Docker Compose;
- механизм захвата трафика: Linux AF_PACKET, PACKET_MMAP и TPACKET_V3;
- хранилище данных: ClickHouse;
- основные C++-зависимости: Drogon и spdlog.

## Среда разработки

- операционная система: macOS;
- контейнерная среда: Docker Desktop;
- основной режим разработки и тестирования: обработка PCAP-файлов.

## Дополнительные требования

Для захвата трафика с сетевого интерфейса процессу необходима capability
`CAP_NET_RAW` либо запуск с соответствующими привилегиями. Производительные
испытания и проверка режима захвата трафика выполняются на Linux-хосте или
Linux-виртуальной машине, поскольку Docker Desktop на macOS не предоставляет
контейнеру прямой доступ к физическому сетевому интерфейсу хоста.
