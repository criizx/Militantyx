# Среда выполнения

## Первый прототип

Офлайн-обработка PCAP и переносимые тесты выполняются на macOS или Linux.
Нужны компилятор C++23, CMake 3.25+, spdlog и Catch2 3. Для полного локального
набора проверок также нужны clang-format, clang-tidy и ShellCheck.
Установка и команды приведены в README.

GitHub workflow использует Ubuntu 24.04 и устанавливает `catch2`, необходимый
для `find_package(Catch2 3 CONFIG REQUIRED)`. Python- и frontend-проверки
подключаются только при наличии соответствующих проектов.

Dockerfile собирает оба тестовых исполняемых файла и запускает CTest.
Готовый образ запускает smoke-тест логирования. Сенсор пока не реализован.
Compose содержит ClickHouse, но код core пока с ним не взаимодействует.

## Экспериментальный стенд

Python-модуль обучения ещё не создан. При реализации нужно зафиксировать
версии зависимостей. Для каждого сравнения записываются модель CPU, объём RAM,
ОС, компилятор, конфигурации, seed и версии данных. Сборка в контейнере на Apple Silicon
не заменяет нагрузочные измерения на целевом оборудовании.

## Будущий live-захват

Для AF_PACKET требуется Linux, CAP_NET_RAW и доступ к нужному интерфейсу.
Docker Desktop на macOS не даёт прямого доступа к физическому интерфейсу хоста.
Live-захват проверяется на Linux-хосте или ВМ с доступом к нужному интерфейсу.

Сенсор получает копию трафика через зеркалирование, TAP или виртуальный
интерфейс. Видимость обоих направлений проверяется отдельно; шлюз не гарантирует
наблюдение всех внутренних связей. При добавлении сервисов Compose они
обращаются друг к другу по именам внутренней сети.
