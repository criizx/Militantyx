# Технологический стек

| Подсистема | Технологии |
|---|---|
| Среда разработки | macOS, Docker Desktop |
| Среда эксплуатации | Linux |
| DPI-ядро и backend | C++23 |
| Захват трафика | AF_PACKET, PACKET_MMAP, TPACKET_V3 |
| Сборка | CMake |
| Веб-сервер и WebSocket | Drogon |
| Хранилище | ClickHouse |
| Модуль машинного обучения | Python, scikit-learn, Isolation Forest |
| Обмен C++ и Python | HTTP, JSON, localhost |
| Веб-интерфейс | React, TypeScript, Vite |
| Визуализация данных | Recharts или ECharts |
| Контейнеризация | Docker Compose |

## Обоснование выбора

C++23 используется для реализации модуля захвата, разбора пакетов и учёта
сетевых потоков. Механизм AF_PACKET с PACKET_MMAP обеспечивает доступ к пакетам
через кольцевой буфер, отображённый в память процесса.

ClickHouse используется для хранения потоков и событий безопасности как
временных рядов, а также для выполнения аналитических запросов веб-интерфейса.
Запись выполняется пакетами через отдельную очередь, что исключает обращение к
базе данных из потока захвата пакетов.

Python и scikit-learn применяются для обучения и применения модели Isolation
Forest. Выделение ML-модуля в отдельный сервис позволяет обновлять модель
независимо от DPI-ядра. Drogon предоставляет REST API и WebSocket-канал,
React и TypeScript используются для реализации веб-интерфейса.
